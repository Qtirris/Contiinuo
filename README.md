# Contiinuo
## Universidad Nacional de Colombia

### Programación orientada a objetos

`Contiinuo` es un sistema de gestión empresarial, orientado a pequeños negocios dedicados a la comercialización de productos electrónicos, que permita administrar de manera organizada y eficiente la información de las cuentas, el inventario de productos y las ventas, con el fin de facilitar el control de las operaciones comerciales, mejorar el manejo de la información y apoyar la gestión administrativa del negocio

## Instrucciones de uso:

### Previo al uso:

1. Descargar la ultima versión en el apartado de Releases del repositorio `https://github.com/Qtirris/Contiinuo`.

2. Descomprimir el archivo `.zip` descargado y acceder a la carpeta `src/`.

3. En caso de tener un IDE instalado (como VSCode) que permita ejecutar archivos `.java` , ejecute `Main.java`.  
De lo contrario será necesario que primero compile todas las clases en la carpeta y luego ejecute la clase `Main`.

### Uso de Contiinuo

1. Primero será necesario que registre los productos que ya hayan en el local a través del menú : *`1. Administrar Inventario`* $\rightarrow$ *`1. Registrar Producto`* y llene los datos que se le solicitan.

2. Una vez tenga productos registrados, pued eintregar al apartado *`2. Registrar Venta`*, llenar los datos solicitados y se le genererá e imprimirá en pantalla la factura correspondiente.

3. Una vez haya registrado ventas, puede revisar algunas estadisticas en el apartado de *`5. Contabilidad`*, dentro de las cuales puede ver las ganancias totales el dia o el dinero total que entró a la caja en el día.

4. Con la opción *`4. Cerrar día`*, puede ver el reporte final del día donde puede ver la cantidad de facturas emitidas, la ganancia o el ticket promedio.

5. Finalmente no olvide explorar el resto de opciones con las que cuenta `Contiinuo`.
